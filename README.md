## Run Locally

Follow these steps to run the project on your local machine.

### Prerequisites

- Node.js (LTS recommended)
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/Manthan19k/manthan-portfolio.git
```

### 2. Navigate to the project directory

```bash
cd manthan-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

### 5. Create a production build

```bash
npm run build
```

### 6. Preview the production build

```bash
npm run preview
```

## Deployment

The portfolio is intended for deployment using **Cloudflare Pages** with GitHub integration.

Recommended build configuration:

| Configuration | Value |
|---|---|
| Framework | Vite |
| Production Branch | `main` |
| Build Command | `npm run build` |
| Build Output Directory | `dist` |

### Automatic Deployment Workflow

Once GitHub is connected to Cloudflare Pages:

1. Make changes to the portfolio.
2. Commit the changes.
3. Push them to the GitHub repository.
4. Cloudflare Pages automatically builds and deploys the updated website.
